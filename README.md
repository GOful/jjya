# 일일업무일지 생성기

브라우저에서 위험예지훈련을 선택해 일일업무일지를 생성하고 복사하는 웹사이트입니다.
별도 서버나 Python 설치 없이 동작합니다.

## 웹사이트 배포

GitHub 저장소의 **Settings → Pages → Build and deployment**에서 다음을 선택합니다.

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

**Save**를 누른 뒤 GitHub Pages 배포가 완료되면 다음 주소에서 사용할 수 있습니다.

https://goful.github.io/jjya/

이 주소는 Pages 활성화 및 배포가 완료된 뒤 접속할 수 있습니다.
배포 이후 `main`의 `index.html`을 수정하면 웹사이트도 자동으로 업데이트됩니다.

## 기능

- 위험예지훈련 23개 항목 및 분류별 필터
- 업무일지 자동 생성 및 본문 편집
- 클립보드 복사 및 확정 시 사용 횟수 증가
- 동일하게 생성한 일지의 재복사 시 중복 집계 방지
- 분류별 사용 횟수 저장 및 모바일 화면 지원

사용 횟수는 각 브라우저의 로컬 저장소에 저장됩니다. 기기 간 공유되지 않으며,
브라우저 데이터 삭제 시 사라집니다. 기존 Python 앱의 JSON 기록은 자동으로 이전되지 않습니다.
로컬 HTML 파일과 배포된 사이트는 서로 별도의 저장소를 사용합니다.

## 로컬 실행

저장소 루트에서 다음 명령을 실행합니다.

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`에 접속합니다.
클립보드 기능은 HTTPS 또는 localhost에서 사용하는 것을 권장합니다.

## 기간별 안전점검

여름철·겨울철·해빙기·풍수해·시설물 일제·설 연휴 중 점검 종류를 고르면
해당 종류의 안전점검 항목과 사용 횟수가 목록으로 표시됩니다.
항목을 누르면 작업 전 안전수칙 아래에 바로 반영됩니다.
종류별 한 항목씩 선택할 수 있으며, 여러 종류를 함께 포함할 수 있습니다.
선택한 항목 옆 × 버튼으로 해당 종류의 점검을 제외할 수 있습니다.

복사 및 확정 시 위험예지훈련과 선택한 안전점검 항목의 사용 횟수를 함께 저장합니다.
같은 일지의 재복사 또는 이미 확정한 점검 항목 재선택 시 중복 집계하지 않습니다.
다른 점검 항목을 추가해 확정하면 새 항목만 집계하며,
위험예지훈련을 다시 선택해 새 일지를 생성하면 새로 집계합니다.
기존 위험예지훈련 사용 횟수는 유지됩니다.

해당 연도 공문에 맞게 시작일과 종료일을 입력하면 일지에 자동 반영됩니다.
시작일과 종료일을 모두 입력해야 하며, 종료일은 시작일보다 빠를 수 없습니다.

## 기타업무

3번 기타업무에서 전력량 검침, 안전점검의 날, 소화기점검, 음주측정기 점검,
소방점검 입회, 바닥왁스 작업 입회를 선택할 수 있습니다.
기간 입력은 없으며 여러 업무를 함께 선택할 수 있습니다.
번호가 붙은 업무명을 선택하면 작성 내용이 4번 업무일지에 표시됩니다.
본문 수정은 4번 업무일지에서 할 수 있습니다.
항목을 다시 누르거나 선택한 업무 옆 × 버튼으로 취소할 수 있습니다.
기타업무는 작업 후 위험예지훈련 바로 위에 삽입됩니다.

## Supabase 공유 저장

2~3명이 로그인 화면 없이 점검 내용, 업무일지, 입력 기간, 사용 횟수를 공유하는
Supabase 연동 기능을 추가했습니다. 활성화 전에는 기존 브라우저 저장 방식을 유지합니다.
프로젝트 설정과 기존 DB의 행 단위 테이블 전환은 [Supabase 설정 안내](supabase/README.md)를 확인하세요.
공유 모드에서는 최근 저장 초안 대신 최근 복사 상태를 우선 복원합니다.

서무업무를 선택하면 `분소행정업무처리`가 스트레칭 항목 바로 아래에 들어갑니다.

갑조·을조·병조 탭에서 같은 점검 내용을 사용하면서 횟수와 최근 복사 상태를 조별로 관리합니다.
기존 기록은 갑조로 배정합니다. 적용 절차는 [조별 설정](supabase/README.md#갑조을조병조-분리)을 확인하세요.

**횟수 수정**에서 조별 횟수를 `− / +`로 보정할 수 있습니다. 매번 자동 저장하며 0 미만으로 내려가지 않습니다.

위험예지훈련 제목 옆 **내용 수정**에서 위험 내용과 작업 전 안전수칙을 공통 수정할 수 있습니다. 조별 횟수는 유지됩니다.

기간별 안전점검과 기타업무도 각 영역의 **내용 수정** 메뉴에서 세 조 공통으로 수정할 수 있습니다.

## 안전교육일지(TBM) 생성기

상단의 **일일업무일지 생성기 / 안전교육일지 생성기** 탭으로 전환합니다.
안전교육 화면은 첨부 HWPX에서 읽은 표의 셀·병합·색상·항목 배치를 웹에서 재현한 문서형 편집 화면입니다.
각 문서 칸 안에서 콤보박스·체크박스·입력란으로 직접 작성합니다.
교육일자·작업 계획·위험요인·확인 결과·참석자를 입력한 후 **HWPX 다운로드**를 누릅니다.
기존 위험예지훈련 내용을 위험요인 선택에 사용하며, 선택한 내용을 해당 문서 안에서 수정할 수 있습니다.
다운로드는 업무일지 복사 횟수를 증가시키지 않으며 이름·서명 등은 공유 DB에 저장하지 않습니다.

- 원본 표의 49개 셀, 병합, 테두리, 글꼴/문단 설정을 유지합니다.
- 위험요인 1~2개, 교육 참석자 최대 4명은 제공된 양식의 칸에 맞춥니다.
- 야간 작업처럼 종료 시간이 다음 날인 입력을 지원합니다.
- 확인 결과는 미확인으로 시작하며 사용자가 선택한 결과만 표시합니다. 서명·결재는 빈칸입니다.
- 예시 파일의 성명·체크 결과·작성자 정보와 이미지 미리보기는 템플릿에서 제거했습니다.
- HWPX는 브라우저에서 직접 생성합니다. 생성한 파일에는 최신 텍스트 미리보기를 넣습니다.
- 문서 보기는 100%/85%/70%/55%로 확대·축소할 수 있고, 좁은 화면에서는 가로로 스크롤합니다.
- 웹 화면은 원본 표 구조를 재현한 HTML 편집이며 한글 렌더링 엔진은 아닙니다.
  긴 문구와 사용자 글꼴에 따른 최종 줄바꿈·인쇄 배치는 한글에서 확인해야 합니다.

`assets/tbm-template.hwpx`는 입력값을 지운 원본 양식입니다. 새 예시 양식으로 템플릿을 다시 만들려면
`python scripts/prepare_tbm_template.py /path/to/example.hwpx`를 실행합니다(Python lxml 필요).
`assets/tbm-layout.js`는 같은 템플릿에서 웹 문서 표를 생성하기 위한 셀 구조이며 템플릿 준비 시 함께 갱신됩니다.
표 구조가 다른 양식은 셀 매핑 변경도 필요합니다. 작성된 원본 파일을 저장소에 올리지 않습니다.

검증: `python tests/browser_tbm.py`는 실제 다운로드의 ZIP CRC/XML, 입력값, 원본 셀 구조,
서명 공란, 예시 작성자 제거와 모바일 화면을 확인합니다. 한글 프로그램에서의 열기/인쇄 검증은 별도입니다.
