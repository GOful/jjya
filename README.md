# 일일업무일지 생성기

브라우저에서 위험예지훈련을 선택해 일일업무일지를 생성하고 복사하는 웹사이트입니다.
별도 서버나 Python 설치 없이 동작합니다.

## 웹사이트 배포

GitHub 저장소의 **Settings → Pages → Build and deployment**에서 다음을 선택합니다.

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

**Save**를 누른 뒤 GitHub Pages 배포가 완료되면 다음 주소에서 사용할 수 있습니다.

https://goful.github.io/jjya/

이 주소는 Pages 활성화 및 배포가 완료된 뒤 접속할 수 있습니다.
배포 이후 `main`의 `index.html`을 수정하면 웹사이트도 자동으로 업데이트됩니다.

## 기능

- 위험예지훈련 23개 항목 및 분류별 필터
- 업무일지 자동 생성 및 본문 편집
- 클립보드 복사 및 확정 시 사용 횟수 증가
- 동일하게 생성한 일지의 재복사 시 중복 집계 방지
- 분류별 사용 횟수 저장 및 모바일 화면 지원

사용 횟수는 각 브라우저의 로컬 저장소에 저장됩니다. 기기 간 공유되지 않으며,
브라우저 데이터 삭제 시 사라집니다. 기존 Python 앱의 JSON 기록은 자동으로 이전되지 않습니다.
로컬 HTML 파일과 배포된 사이트는 서로 별도의 저장소를 사용합니다.

## 로컬 실행

저장소 루트에서 다음 명령을 실행합니다.

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`에 접속합니다.
클립보드 기능은 HTTPS 또는 localhost에서 사용하는 것을 권장합니다.

## 기간별 안전점검

여름철·겨울철·해빙기·풍수해·시설물 일제·설 연휴 점검에서 필요한 종류와 세부 항목을 선택할 수 있습니다.
해당 연도 공문을 확인하여 시작일과 종료일을 입력한 후 **선택한 안전점검을 일지에 반영**을 누릅니다.
점검 내용은 작업 전 안전수칙 아래, 작업 후 위험예지훈련 위에 삽입됩니다.
기간은 자동으로 적용되지 않으며, 제공된 과거 기간은 참고용으로 표시됩니다.
위험예지훈련을 새로 선택할 때도 현재 선택한 점검이 포함됩니다.
